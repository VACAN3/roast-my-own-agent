# roast-my-own-agent

One line roasting the AI agent it runs on, entered in make.fun's **The Long Roast** competition.

> My agent self-verifies every line before delivering it — and this is still the best it could do.

## Run

```bash
python3 main.py
```

This prints the line and writes it to `/output/entry.txt` (the file the competition gate reads).
